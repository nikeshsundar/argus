Reference

Everything Argus does,
and exactly how to reach it.

Argus has no settings window. Everything lives behind one hotkey and a handful of slash commands, so every feature below is three keystrokes away from wherever you already are.

Press Alt + ` anywhere to open the bar Type / for the command palette Esc closes it, and stops the agent

Asks

Talk Mode

Ask a question about whatever is on your screen right now. Argus captures the display the instant you press the hotkey — before its own window appears — so it sees what you were looking at, not the bar you just opened.

How to get there

Press Alt + ` and just type a question. It is the default — no prefix needed.

If a question reads like an order and gets routed to the agent by mistake, prefix it with ask.

Try it with
> what is this error telling me?
> summarise this page in three bullets
> ask what does this graph actually show
Good for
  • Errors you cannot parse. A stack trace, a Windows error code, a red squiggle in an IDE — without retyping any of it into a chat window
  • Dense screens. A spreadsheet, a dashboard, a legal PDF: "which of these numbers is the one that changed?"
  • Another language. An interface, a document, a menu — it reads what is rendered, so nothing has to be selectable
  • Follow-ups. The screenshot stays attached to the conversation, so "and the one below it?" works without re-capturing
Worth knowing

The screenshot lives in RAM and is dropped when you dismiss the bar. Saved conversations keep the text, never the image.

Acts

Agent Mode

Hand over the keyboard and mouse. Argus looks at the screen, takes one action, looks again, and repeats until the task is done — clicking and typing on your real desktop, in whatever apps you already have open.

How to get there

Type an instruction. Anything imperative is routed to the agent automatically — no magic word.

Click the Talk chip to force it, or prefix with agent when the wording is ambiguous.

Try it with
> open notepad and write a shopping list
> go to github.com and open my notifications
> agent find the cheapest flight to Chennai tomorrow
Good for
  • Fiddly sequences you know but hate. Six clicks buried in a settings tree you have to rediscover every time
  • Apps with no API. Legacy desktop software, an intranet portal, anything where scripting was never an option
  • Reading something out of a UI. Ask it to check or summarise and the answer comes back — not a description of the clicking
Take over any time

Click, type or scroll and the agent stands down between steps and gives you the machine back. Go quiet for three seconds and it resumes where it left off. The frame turns from amber to grey so you always know who is driving.

Hold Esc to stop it outright, mid-movement.

Where it stops
  • Fourteen actions per task. A confused agent cannot grind forever
  • It notices when it is going in circles — the same action twice earns a correction, three times ends the task honestly rather than burning the remaining steps
  • Two minutes of you working abandons the task, because the screen it planned against is gone by then
  • Follow-ups work: the last few tasks and how each turned out are carried into the next one, so "open it in Edge instead" means something
Shows

Teach Mode

The inverse of Agent Mode: ask to be taught and it refuses to do it for you. A blue ghost cursor appears over the real control, captioned with what the step does and why — and then it waits. You click. It looks at the new screen and points at the next thing.

How to get there

Start your request with teach me, then click the chip to Agent so it points at your screen rather than writing out steps.

Left on Talk, the same words give you a numbered written walkthrough instead — useful when you want something you can keep.

Try it with
> teach me how to change my display resolution
> teach me how to export this as a PDF
Good for
  • Learning software you will use again. Being shown where a control is teaches you where it is; being done for teaches you nothing
  • Helping someone remotely. They keep the mouse the whole time
  • Anyone wary of handing over control. This is the mode to start with — the worst it can do is point at the wrong button
Worth knowing

Teach Mode never touches your mouse or keyboard. The ghost cursor is a drawing on a click-through overlay; every real click is yours. Nothing advances on a timer, so a step stays up for as long as you need.

Press Space or Enter to skip ahead a step, Esc to end the lesson.

Input

Voice

Long instructions are miserable to type and effortless to speak, which is exactly what Agent Mode asks for. Click the mic, say it, click again.

How to get there

Click the microphone button in the bar. Click it again to stop. The bar turns red and the mic pulses while it is live.

What you get

"um, open youtube and uh search for mister beast" becomes "Open YouTube and search for MrBeast".

Fillers, false starts and misheard brand names are cleaned up as part of transcribing, so you get what you meant rather than a literal transcript.

Worth knowing
  • Never a wake word. Nothing listens in the background — recording only ever starts from that click
  • Esc discards a recording, and one stops itself after 60 seconds so a forgotten mic cannot stay open
  • Talk Mode sends straight away; Agent and Teach put the text in the box and wait for Enter, because speech misheard by one word should not move your mouse
  • Argus never speaks back. This is dictation, not a conversation

Screen Memory

Ask about something that is already gone. Argus can keep a short rolling record of what has been on your screen — in RAM, never on disk — so a question does not have to be about what is in front of you right now.

How to get there
> /memory on # keep the last 10 minutes
> /memory on 30 # or any number of minutes, up to 60
> /memory # what is held, and how far back
> /memory purge # forget everything, now
> /memory off # stop, and forget everything
Then ask
> /recall what was that error code
> what was the price on that tab I closed
> what have I been doing for the last 10 minutes

You do not have to type /recall. While memory is on, a question that could only be about the past is answered from the timeline automatically.

Good for
  • The dialog you dismissed too fast. The single most common reason to want this
  • A tab you closed — the price, the order number, the phone number you did not write down
  • Standup notes. "What have I been doing" produces a short chronological list of apps and pages
  • Where did I see that? When you know you read something in the last ten minutes but not where
How it answers
  • Every frame is dated. The answer says when it saw the thing — "3m ago, in the Chrome window" — so you can go back and check
  • It quotes, it does not paraphrase. Error codes and prices come back character for character, and "it is not in the last 10 minutes" is a valid answer. A plausible invented error code is the one failure you could not detect
  • The live screen is always included, so "is that still up" and "what changed" have a now to compare against
This is the only feature that looks at your screen without you pressing anything — so it is off until you turn it on, and it is meant to be obvious when it is not. A red ● 10m pill sits in the bar every time you open it, and it is a button: hover it and it reads Stop, click it and recording ends and everything held is forgotten — no dialog in the way. The tray tooltip says so too. Frames are JPEGs in one process and nowhere else: /memory off, /memory purge and quitting each drop them, nothing survives a restart, and recording stops entirely while Argus's own windows are up. Nothing is sent anywhere until you ask a question.

Saved Workflows

Agent Mode costs a model call per step and most of a minute per task, against a free tier of twenty calls a day. But the second time you ask for the same thing, the answer is already known — so save the run and replay it for nothing.

How to get there

Run an Agent task. When it succeeds, the result offers to keep it.

> /save morning # keep the last successful run
> /workflows # list them, with step counts
> /workflows morning # every step, before you run it
> /run morning # replay - no model call at all

Typing the workflow's name on its own in Agent Mode replays it too.

Good for
  • The same setup every morning. Open the four apps, land on the right tab
  • Anything you have already watched succeed once. A replay is a shortcut, not a scheduler
  • Staying inside the free tier. A replay costs nothing and finishes in seconds instead of a minute
Where it stops
  • It records the agent's actions, not yours. Watching you would mean a keylogger running all day, in an app whose whole promise is that it is not watching
  • Only successful actions are kept, and a replay stops at the first failure rather than typing the rest into whatever is now on screen
  • It refuses to run on a differently shaped screen. 1080p to 4K is fine; 16:9 to ultrawide moves every control, and a blind click would land on whatever now occupies that spot
A replay is deliberately blind. A live agent looks before every action; a replay skips the screenshot and the model call, which is precisely what makes it free and quick. It clicks the coordinates that worked last time. Replay what you would be happy to watch happen.
Setup

Choosing a model

Argus is bring-your-own-key, so which model answers is your call. /aimodel lists what can answer and you pick — Gemini's free tier is the default, so Argus is usable the minute you install it.

How to get there
> /aimodel # the menu, numbered
> /aimodel 3 # pick by row number
> /aimodel claude sonnet # or by name
> /model <id> # a raw id, for anything unlisted
On the menu
  • Gemini Flash — free tier, 20 requests a day, no card. The default
  • Claude Sonnet, Opus or Haiku — paid; reads cluttered screens and small text best
  • GPT-5 and GPT-5 mini — paid
  • Ollama — free and offline, running on your own machine
Worth knowing
  • The menu marks which rows are ready and which need a key before you pick one, rather than letting you find out a request later
  • An ambiguous name is refused, not guessed. /aimodel claude is fine; /aimodel flash matches two models and says so
  • Agent and Teach Mode run on Gemini regardless: they make a dozen quick "which control next" calls per task, which is a different job from one answer worth waiting for
Setup

API keys

Your key stays on your machine. There is no Argus server — your screen goes to the model provider you chose, and nowhere else.

How to get there
> /key <your-key> # filed by its own format
> /keys # the rotation, and which are resting
> /keys k1 k2 k3 # load several at once
> /keys reset # clear cooldowns, retry everything

Get a free Gemini key at aistudio.google.com/apikey — no card required.

Worth knowing
  • You never have to say which provider a key belongs to. sk-ant-…, sk-… and AIza… each route themselves, and Talk Mode switches with them
  • Keys stack rather than replace. One over quota hands off to the next automatically
  • Quota is per Google Cloud project, so a second key only buys headroom if it comes from a different project
  • Paste a bare key into the bar without /key and it is still recognised — never sent to the model, never written to the transcript

Chat history

Conversations persist across sessions, so you can pick up something you were asking about yesterday.

How to get there
> /history # browse and resume
> /new # start fresh
> /forget # delete every saved chat
Worth knowing
  • Text is saved; screenshots never are. A resumed conversation remembers what was said about a screen, not the screen
  • /new clears what the agent remembers too, so a follow-up cannot quietly continue a task you thought you had cleared away
Setup

The hotkey

Alt + ` by default, from anywhere in Windows. Press it again, or Esc, to dismiss.

How to change it
> /hotkey Control+Alt+Space

If Windows refuses to give up the combination, Argus says so and keeps the one that works rather than leaving you with no way in.

Worth knowing
  • The obvious pick, Win + `, is already Windows Terminal's — a hook can see the key without being able to stop the other app receiving it, so it would open a terminal too
  • Ctrl + Space is avoided as well: it toggles IME language input and loses to the OS
  • Argus also lives in the system tray — click the icon to open the bar

Pointer pace

The pointer travels rather than teleporting — an eased glide with a halo and a click ring — so you can follow every move instead of watching things happen.

How to get there
> /cursor natural # the default - quick, still followable
> /cursor demo # slow and deliberate, for recording
> /cursor instant # no show at all
Good for
  • demo when you are screen-recording, or showing someone what the agent is doing
  • instant when you have stopped watching and just want the task finished

Argus

Named for Argus Panoptes, the hundred-eyed giant of Greek myth — always watching, never asleep. This one only opens its eye when you ask.
