we all have the same models in a browser tab. almost nobody has one that can see the thing they are stuck on.

you already know the feeling. an error you cannot parse, a settings panel with forty switches, a video with no captions — and the only way to ask about it is to screenshot, crop, upload, and describe what you already had in front of you.

argus removes that whole trip. one hotkey, and the model is looking at the same pixels you are. ask, or say agent and let it drive.

no account, no server of mine in the middle, no telemetry. your key, your machine, your screen. it is early — try it and tell me what breaks.

what it does

two modes. one hotkey.

talk mode

ask about anything you are looking at — then keep asking

Argus captures the screen once, sends it with your question, and keeps the thread going. Follow-ups resolve against what was already discussed, so you never have to re-explain yourself.

  • Understands screenshots, not just text — errors, dashboards, videos, code
  • Every conversation is saved as a resumable thread
  • Works with a free Gemini API key

agent mode

say agent, describe the task, watch it get done

Argus looks at the screen, decides one action, performs it, then looks again — the same loop a person uses, not a blind script. A pulsing frame stays on screen the entire time, so it never operates silently.

  • Launches real apps directly — no typing into Windows Search, no stray browser tabs
  • One action at a time, re-checked against the screen after every step
  • Esc stops it instantly, from anywhere, no matter what has focus

privacy, by construction

your screen is the most personal data you have

Argus was built around one rule: nothing is captured until the hotkey is pressed, and nothing captured ever touches disk. Only text — never an image — is saved to your chat history.

  • Screenshots live in RAM only, discarded once a request finishes
  • No Argus servers. Your screen goes to the model provider you choose, and nowhere else
  • Fully self-hostable — read every line, or fork it

get it running

ten minutes, and you have never opened a terminal before

There is no installer yet — you build it from the source, which is four commands. Every step below says what you should see when it worked, so you always know whether to carry on.

0

Install the two things Argus needs

Both are free, both are one-click installers, and you only ever do this once. Take the defaults on every screen.

  • Node.js — click the big LTS button. This is what runs Argus.
  • Git for Windows — this is what downloads the code. You can skip it; see step 1.

Then restart your computer. Installers add things to a list Windows only re-reads on startup, and skipping this is the single most common reason the next step fails.

1

Open a terminal, and check they are there

Press Win + R, type powershell, press Enter. A blue-black window opens. That is the terminal — you type commands into it and press Enter.

powershell
> node -v
> git --version

Worked if each prints a version number, like v22.14.0. If either says "not recognized", that thing did not install — or you have not restarted since.

2

Download the code

Paste both lines, one at a time. This puts Argus in your user folder.

powershell
> git clone https://github.com/nikeshsundar/argus.git
> cd argus

Worked if the text before the cursor now ends in \argus>. That means you are inside the folder, which the next commands need.

No Git? Download the ZIP, right-click it, Extract All. Then in the extracted folder, hold Shift, right-click empty space, and choose Open PowerShell window here — you can skip straight to step 3.

3

Install and start it

The first command downloads what Argus is built from and takes a minute or two. It is noisy; that is normal.

powershell
> npm install
> npm run dev

Worked if a small bar appears in the middle of your screen. Argus lives in the system tray — the little icons by the clock. No app window opens, and nothing appears in the taskbar. That is not a mistake, it is the whole point.

Leave that terminal open. Closing it quits Argus. Minimise it instead.

4

Get a free key from Google

Argus does not have its own AI — you point it at one. Google's free tier needs no card and takes about a minute.

  1. Go to aistudio.google.com/apikey
  2. Sign in with any Google account
  3. Click Create API key
  4. Pick any project it offers, or let it make one
  5. Click Copy. The key is a long string starting AIza…

Keep it private. It is a password to your Google AI account. Argus stores it on your machine and sends it nowhere but Google.

5

Paste the key into Argus

Press Alt + ` — that is the key above Tab, left of 1. The bar appears. Type /key, a space, then paste with Ctrl + V, and press Enter.

argus
/key AIzaSy…your-key-here

Worked if the bar replies "Gemini API key saved. Ask away."

6

Ask it something

Open anything at all — a web page, an error message, a spreadsheet. Press Alt + ` and type a question about what you are looking at.

argus
what is this page about?
agent open notepad and write a shopping list

That is everything. Type /help in the bar to see the rest, or read the full feature guide.

what you need
  • Windows 10 or 11
  • Node.js — free, one click
  • A free Google Gemini key — no card
  • About ten minutes
if something went wrong
  • "npm is not recognized" — Node.js is not installed, or you have not restarted since installing it.
  • Nothing appeared — Argus has no window. Look in the system tray by the clock, and press Alt + `.
  • The hotkey does nothing — another app already owns it. Click the tray icon to open the bar, then type /hotkey Control+Alt+Space.
  • "Every Gemini key is over quota" — the free tier is 20 requests a day. Add a second key from a different Google project with /key; quota is counted per project.
  • It stopped after you closed the terminal — that terminal was running it. Run npm run dev again.
prefer a real .exe?

Build a one-click installer for yourself, then you never need the terminal again:

> npm run package

It appears in the dist folder. Run it once and Argus installs like any other program.

everything is set in the bar
  • /tutorial — the guided tour, no key needed
  • /help — list every command
  • /aimodel — choose which AI answers
  • /hotkey — rebind the shortcut
  • /history — resume a past chat

four things keep that honest

visible always

A pulsing red frame covers the screen the entire time it has control. It can never operate silently.

instant stop

Esc kills it immediately, from anywhere, whether or not Argus has focus.

hard ceiling

Every task is capped at 14 actions, so a confused model can't grind on indefinitely.

It re-reads the screen after every action rather than firing a blind sequence.

faq

frequently asked questions

what to know about argus, privacy, and getting started.

what is argus?
A screen-aware AI assistant that lives in your Windows tray. Press the hotkey and it sees what you see, so you can ask it anything about whatever you are working on — or say agent and it goes and does the task for you.
i just installed it — where do i start?
Press the hotkey and type /tutorial. It is a guided tour of every mode, read inside the bar, and it is the one thing that works before you have set an API key — so it answers "what did I just install?" at the moment you are actually asking. Enter turns the page; /tutorial exit leaves.
is my data private?
Yes, structurally. There is no Argus server: the screenshot goes straight from your machine to the model provider you chose, using your key. Screenshots are held in RAM and discarded when the request finishes — they never touch disk. Only text is saved to your chat history, on your machine.
is argus watching my screen all the time?
No. Nothing is captured until you press the hotkey. Between presses it is an idle tray icon.
what can it actually do?
Explain anything on screen, walk you through a tool you have never used, and — in Agent Mode — launch apps, click, type and scroll to finish a task for you. Teach Mode records a workflow once so you can replay it later.
what is the difference between talk and agent?
Talk answers questions about the screen; it never touches your mouse or keyboard. Agent takes control and performs actions. Acting is the default — anything that does not read like a question goes to the agent. The chip on the bar names the mode before you press Enter, the screen carries a red frame the whole time the agent has control, and Esc stops it instantly from anywhere.
which apps does it work with?
Anything you can see. Argus reads pixels, not APIs, so there is nothing to integrate — games, PDFs, remote desktops and video all work the same way.
do i need windows?
For now, yes — Windows 10 or 11. The screen capture and input simulation are Windows-specific; macOS and Linux are on the roadmap.
is it really free?
Argus is MIT licensed and always free. The only possible cost is the model behind it, and Google's Gemini free tier covers most people at $0 with no card.
what happens if i hit the free tier limit?
You will see "Every Gemini key is over quota". Add a second key from a different Google project with /key — quota is counted per project, and Argus rotates through the keys it has. Or point it at a paid key with /aimodel.
can i fork it?
Yes. MIT license, no strings. Fork it, rename it, ship it commercially — a link back is appreciated but not required.
